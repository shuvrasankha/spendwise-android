Use your own AI key in SpendWise

SpendWise's AI features (Ask, the coach, budget suggestions, voice entry, receipt scans and CSV import) work out of the box with SpendWise AI, which has daily limits. With your own API key, from one of five providers, there are no SpendWise limits: your provider sets the limits and the price.

An API key is a long password that lets an app use your account with an AI provider. It is stored encrypted on your phone only and goes nowhere except that provider.

Choose a provider:

  • Google Gemini: has a free tier. A good first choice.
  • Groq: has a free tier and is very fast.
  • NVIDIA: free credits for developers.
  • OpenAI: pay as you go.
  • Anthropic: pay as you go.

Free tiers and prices change. Check the provider's pricing page before you rely on one.

Google Gemini

  1. Open aistudio.google.com/apikey and sign in with a Google account.
  2. Accept the terms if asked, then choose Create API key.
  3. Copy the key. It starts with AIza.

Groq

  1. Open console.groq.com/keys and sign up or sign in.
  2. Choose Create API Key and give it a name, such as "SpendWise".
  3. Copy the key straight away: Groq shows it only once. It starts with gsk_.

NVIDIA

  1. Open build.nvidia.com and sign in with an NVIDIA account (creating one is free).
  2. Open your account's API keys page, or any model's page, and choose Get API Key or Generate API Key.
  3. Copy the key. It starts with nvapi-.

OpenAI

  1. Open platform.openai.com/api-keys and sign in. This is the developer platform, separate from a ChatGPT subscription.
  2. Add a payment method or prepaid credit under Billing: the API doesn't answer without it.
  3. Back on API keys, choose Create new secret key, name it "SpendWise", and copy it. OpenAI shows it only once. It starts with sk-.

Anthropic

  1. Open platform.claude.com and sign in. This is the developer platform, separate from a Claude subscription.
  2. Buy prepaid credit under Billing: the API doesn't answer without it.
  3. Open API Keys, choose Create Key, name it "SpendWise", and copy it. It's shown only once. It starts with sk-ant-.

Add the key to SpendWise

  1. In SpendWise, open Settings › AI provider.
  2. Choose My own API key, then pick your provider.
  3. Paste the key and tap Save key.
  4. Tap Test connection. "Connection works." means the key is good.
  5. Tap Set [provider] as AI provider, and agree to send AI requests to that provider.

From then on, the AI features use your key. To go back, choose SpendWise AI on the same screen: your key stays saved for later.

Models

SpendWise picks a model for each provider, so you can leave the model fields empty. To use another one, type its exact name from the provider's model list, then tap Test connection. The vision model must be able to read images, for receipt scans.

Keep your key safe

  • Treat the key like a password: never share it or post it anywhere.
  • For a paid provider, set a monthly spending limit on its billing page.
  • If you lose your phone or think the key leaked, delete the key on the provider's site, then make a new one.
  • To remove it from SpendWise, open Settings › AI provider and tap Remove.

What your provider sees

With your own key, AI requests go straight from your phone to your provider, under that provider's terms and privacy policy. They don't pass through SpendWise's servers, and SpendWise can't see your usage or balance. What each feature sends is set out in the privacy policy.
